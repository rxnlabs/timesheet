# Designs

This folder contains the design resources and mockups I created to visually outline the user interface and experience for the **Timesheets Application** project. These designs act as a blueprint for the application's layout and functionality, providing a clear foundation for implementation.

## Figma

- **[Version 1 (v1)](https://www.figma.com/design/MwAc8sMjuMapyRB549vh7h/Timesheets-Application?m=auto&t=v18BjvuUPBCox9n0-6)**:  
  This is the initial version of the Timesheets Application design. It includes:
    - A shift entry form for adding work hours.
    - A timesheet table to display entries in an organized format.
    - An archive page for viewing historical timesheets.

📝 **Note**: Earlier PHP+React versions 1–5 of this project do not reflect this updated design.
